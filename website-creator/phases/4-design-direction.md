# Phase 4: Design direction

Goal: A distinct visual world for exactly this site, chosen by the user and recorded as a direction contract. No template, no standard look.

This is the phase that decides between "looks like every AI website" and "looks like my brand".

## Flow

1. Start `/impeccable` with a clear brief: type of site (new landing page or redesign), brand profile from phase 1, chosen references from phase 2, a pointer to `copy.md`. Mention an old site or an old draft only as a counterexample. impeccable loads `PRODUCT.md` itself.
2. **Seven distinct directions** derived from the audience's world, from at least three different material families. For a consultancy for mid-sized companies, for example: process map, technical drawing, railway timetable, hydraulic engineering, workshop. The most obvious idea (for a brand called "Compass" that would be a compass needle) counts only once.
3. **Draw lots** with `concept-seed`: the draw picks which of the seven gets built and deals challengers from impeccable's catalog. That way you don't automatically end up with the standard.
4. **Weigh the challengers honestly.** Rejected directions still each pass one strength on to the main direction.
5. **Show the selection page.** impeccable builds a page with cards (colors, materials, sketch of the first screen). The user picks. Re-rolling, "safer" and "bolder" are possible.
6. **Direction contract** recorded (impeccable stores it under `.impeccable/surfaces/`): thesis, own world, story while scrolling, first screen, form language, ending.

## What makes a good direction

- **One idea carries the whole site.** For a garden nursery, for example, the gardening year: the sections follow the seasons, the process is a bed that grows while scrolling. Every element follows from the same metaphor.
- **The metaphor fits the offer.** It tells something about the service. A metaphor without a connection is decoration.
- **One oversized element per section**, the rest calm.
- **The accent stays rare.** The accent color sits on a few words, not in every heading.

## Sign-off

The user picks a direction on the selection page. Nothing gets built without a choice.

## Done when

- [ ] Seven directions worked out, at least three material families.
- [ ] The user has picked one.
- [ ] The direction contract is in the project.
