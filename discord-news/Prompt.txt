Create a new skill with the following specification.

Name: discord-news

Description: Posts news, articles and announcements to a configured Discord channel. Trigger when the user shares a link and wants to post it on Discord, says "post this to DC", "make discord news", "share this on Discord" or similar.

Server: YOUR_SERVER_NAME
Channel: YOUR_CHANNEL_NAME
Direct URL: https://discord.com/channels/YOUR_SERVER_ID/YOUR_CHANNEL_ID

Important for typing in Discord:
Discord sends the message on Enter. Line breaks require Shift+Enter. When typing, never put newline characters into a string; type each line separately and separate the lines with Shift+Enter.

Workflow:

Step 1: When the user shares a URL, fetch the article via web fetch or navigate to it in the browser and extract the title, main points and date.

Step 2: Navigate to the channel URL.

Step 3: Find the message input field with the find tool.

Step 4: Type the message in the following format. First line: a bold title with an emoji. Blank line with Shift+Enter. One or two sentences of summary. Blank line. Three to six bullet points with the most important points. Blank line. Source URL at the end.

Step 5: Take a screenshot that shows the message in the input field. Ask the user whether to send it.

Step 6: Only after an explicit yes, send with Enter. Take a screenshot as confirmation.
